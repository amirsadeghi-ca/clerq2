# Interpret Logo Package

Minimal folded-document mark with a geometric capital I.

## Colors

- Primary indigo: `#6366f1`
- Fold indigo: `#4f46e5`
- Light background: `#ffffff`
- Dark background: `#0a0a0a`

## Folders

- `svg/` contains the source vector assets.
- `png/transparent/` contains transparent PNG exports of the mark.
- `png/light/` contains PNG app icons on white.
- `png/dark/` contains PNG app icons on near-black.
- `favicon/` contains web favicon assets, Apple touch icon, Android icons, and a web manifest.

Use `svg/interpret-mark.svg` when the surrounding UI supplies the background. Use the light or dark app-icon files when the icon itself needs a fixed square background.
